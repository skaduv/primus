# features

按功能划分的界面模块（第 16.3 节）：

| 目录 | 内容 |
|---|---|
| `chat/` | 时间线、输入框、消息操作、工具卡片、确认框 |
| `sessions/` | 会话列表、会话树 |
| `context/` | 上下文条、固定项 |
| `changes/` | 右栏 · 变更与 Diff |
| `files/` | 右栏 · 文件树与预览 |
| `plan/` | 右栏 · 计划与待办 |
| `settings/` | 设置页 |
| `capabilities/` | 能力中心（扩展、技能、提示模板、MCP） |
| `usage/` | 用量统计 |
